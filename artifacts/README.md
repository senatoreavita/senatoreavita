# Planning artifacts (source of truth: claude.ai)

These HTML files are the committed source for the live planning artifacts on
claude.ai. The claude.ai copy is what the team views; this folder is the durable,
version-controlled backup (the working copies otherwise live only in an ephemeral
scratchpad). When you edit an artifact, republish it to its URL **and** update the
file here so the two stay in sync.

| File | Artifact | claude.ai URL |
|------|----------|---------------|
| `launch-timeline.html` | Launch Timeline | https://claude.ai/artifact/EaSZbUPiVuLd3xuD5NPymg |
| `mission-control.html` | Mission Control | https://claude.ai/artifact/AYoY5uQBX52sd64eWjPbpp |
| `launch-readiness.html` | Launch Readiness | https://claude.ai/artifact/YXKY3AbDTfHgsXbyX7bjon |

Per the repo's standing rule, the Launch Timeline and Mission Control carry a
displayed "Updated" stamp that must be set to the current UTC time on every
republish.
